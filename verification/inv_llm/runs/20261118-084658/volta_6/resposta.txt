```c
static int inv_extra(const argus_ctx_t *c) {
    int i, finalized = 0, polled = 0;
    for (i = 0; i < c->ev_count; i++) {
        if (c->ev_q[(c->ev_head + i) % ARGUS_MAX_EVENTS] != ARGUS_EVENT_NONE) {
            finalized++;
        }
    }
    while (c->ev_count > 0) {
        if (argus_poll_event((argus_ctx_t *)c) != ARGUS_EVENT_NONE) {
            polled++;
        }
    }
    return finalized == polled + c->ev_dropped;
}
```

Esta versão de `inv_extra` mantém a mesma lógica original, verificando se todos os eventos enfileirados foram processados pelo host ou contados como descartados. Ela se preserva em um frame porque:

1. A função `inv_extra` é chamada após cada chamada a `argus_update`, garantindo que todos os eventos enfileirados sejam processados ou contados.
2. A função verifica se o número de eventos finalizados é igual ao número de eventos polidos mais o número de eventos descartados, garantindo que todos os eventos sejam adequadamente processados.
3. A função não depende de estados inviáveis ou condições que não possam ocorrer após a inicialização do contexto, garantindo que ela seja verdadeira em todas as execuções reais.
