```c
static int inv_extra(const argus_ctx_t *c) {
    int i, j, same_age, same_missed;

    /* coerencia estado <-> numero de tracks */
    if (c->state == ARGUS_IDLE && c->n_tracks != 0) return 0;
    if (c->state == ARGUS_TRACKING && c->n_tracks <= 0) return 0;

    for (i = 0; i < ARGUS_MAX_TRACKS; i++) {
        if (!c->tracks[i].active) continue;

        /* missed so cresce junto com age e nasce 0 com age 1 */
        if (c->tracks[i].missed > c->tracks[i].age - 1) return 0;

        /* no maximo MAX_DETS tracks nascem (ou casam) por frame */
        same_age = 0;
        same_missed = 0;
        for (j = 0; j < ARGUS_MAX_TRACKS; j++) {
            if (!c->tracks[j].active) continue;
            if (c->tracks[j].age == c->tracks[i].age) same_age++;
            if (c->tracks[j].missed == c->tracks[i].missed) same_missed++;
        }
        if (same_age > MAX_DETS) return 0;
        if (same_missed > MAX_DETS) return 0;
    }
    return 1;
}
```

Em um frame, todos os tracks ativos fazem `age++`. Cada um deles ou zera `missed`, o que exige `age >= 2`, ou faz `missed++`, então `missed <= age-1` se mantém; um track novo entra com `age=1` e `missed=0`. Como há no máximo `MAX_DETS` detecções, no máximo `MAX_DETS` tracks podem casar ou nascer no frame. Esses são os únicos que ficam com `missed=0` ou `age=1`; os demais apenas deslocam em bloco, em +1, os valores que já respeitavam o limite, e os finalizados só saem da contagem. Quanto ao estado, a máquina só entra em IDLE com `n_tracks==0` e só entra em TRACKING com `n_tracks>0`. Ela permanece em TRACKING apenas se nenhum track foi encerrado no frame, e nesse caso `n_tracks` não diminui.
