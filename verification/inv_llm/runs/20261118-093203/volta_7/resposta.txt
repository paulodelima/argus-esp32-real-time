```c
static int inv_extra(const argus_ctx_t *c) {
    int i, active = 0;
    for (i = 0; i < ARGUS_MAX_TRACKS; i++) {
        if (c->tracks[i].active) {
            active++;
            if (c->tracks[i].id < 1 || c->tracks[i].id > 0x3FFFFFFF) return 0;
            if (c->tracks[i].age < 1 || c->tracks[i].age > ARGUS_MAX_AGE) return 0;
            if (c->tracks[i].missed < 0 || c->tracks[i].missed > ARGUS_MAX_MISSED) return 0;
        }
    }
    if (active != c->n_tracks) return 0;
    return 1;
}
```

Esta versão de `inv_extra` mantém a mesma lógica que a versão anterior, mas não verifica a validade dos IDs dos tracks se `c->n_tracks` for zero. Isso é porque, se não houver tracks ativas, não há como ter IDs inválidos ou IDs que não estejam dentro do intervalo permitido.

A propriedade `P4` é preservada porque, se `c->n_tracks` for zero, não haverá tracks para serem descartados ou contados, e a verificação de IDs será ignorada. Isso significa que, se o estado inicial for inválido, ele não será aceito, e se o estado for válido, ele será aceito.
