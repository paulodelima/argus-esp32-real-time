```c
static int inv_extra(const argus_ctx_t *c) {
    int i, j;
    for (i = 0; i < ARGUS_MAX_TRACKS; i++) {
        int dist;
        if (c->tracks[i].active != 0 && c->tracks[i].active != 1) return 0;
        if (!c->tracks[i].active) continue;
        if (c->tracks[i].id < 1 || c->tracks[i].id > 0x3FFFFFFF) return 0;
        /* quantos ids foram emitidos desde a criacao do track (ciclico) */
        dist = c->next_id - c->tracks[i].id;
        if (dist <= 0) dist += 0x3FFFFFFF;
        if (dist < 1 || dist > c->tracks[i].age * MAX_DETS) return 0;
        for (j = i + 1; j < ARGUS_MAX_TRACKS; j++)
            if (c->tracks[j].active == 1 && c->tracks[j].id == c->tracks[i].id)
                return 0;
    }
    return 1;
}
```

O campo `active` só recebe os valores 0 ou 1. Em cada frame, `next_id` avança no máximo MAX_DETS posições (com wrap) enquanto a `age` de todo track sobrevivente sobe 1, e um track novo nasce com `id` igual ao `next_id` antigo, ou seja, com dist ≤ MAX_DETS e `age`=1. Assim, 1 ≤ dist ≤ `age`·MAX_DETS ≤ 60·MAX_DETS < 0x3FFFFFFF se mantém, o que garante que nenhum id ativo coincide com `next_id`, e portanto o id do track novo é distinto de todos os existentes, preservando a unicidade.
