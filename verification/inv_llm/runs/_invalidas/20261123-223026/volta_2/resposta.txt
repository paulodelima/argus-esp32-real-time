```c
static int inv_extra(const argus_ctx_t *c) {
    int i, j;
    for (i = 0; i < ARGUS_MAX_TRACKS; i++) {
        int a = c->tracks[i].active;
        int dd;
        if (a != 0 && a != 1) return 0;
        if (!a) continue;
        if (c->tracks[i].id < 1 || c->tracks[i].id > 0x3FFFFFFF) return 0;
        if (c->tracks[i].age < 1 || c->tracks[i].age > ARGUS_MAX_AGE) return 0;
        /* distancia ciclica (modulo 0x3FFFFFFF) de id ate next_id */
        dd = c->next_id - c->tracks[i].id;
        if (dd <= 0) dd += 0x3FFFFFFF;
        if (dd < 1 || dd > c->tracks[i].age * MAX_DETS) return 0;
        for (j = i + 1; j < ARGUS_MAX_TRACKS; j++)
            if (c->tracks[j].active && c->tracks[j].id == c->tracks[i].id)
                return 0;
    }
    return 1;
}
```

O estado de partida é excluído porque um track ativo tem `id == next_id` (0x3FFFFFFF), ou seja, distância cíclica 0. Isso só aconteceria se mais de 2^30 IDs fossem emitidos durante a vida do track, mas cada track vive no máximo 60 frames, com no máximo MAX_DETS IDs novos por frame.

Ao ser criado, um track recebe `id = next_id` com `age = 1`. Depois dele, no mesmo frame, saem no máximo MAX_DETS−1 IDs, então a distância fica em [1, MAX_DETS]. A cada frame seguinte, `age` sobe 1 e a distância sobe no máximo MAX_DETS, porque o wrap de `next_id` coincide com o módulo usado no cálculo. Assim, `dd ≤ age*MAX_DETS ≤ 60*MAX_DETS < 0x3FFFFFFF` se mantém.

Os IDs novos são frescos (distância 0 antes de avançar `next_id`) e os IDs existentes nunca mudam, por isso a unicidade entre tracks ativos e `active ∈ {0,1}` também se preservam.
