```c
static int inv_extra(const argus_ctx_t *c) {
    int i, ativos = 0;
    for (i = 0; i < ARGUS_MAX_TRACKS; i++) {
        if (!c->tracks[i].active) continue;
        ativos++;
        if (c->tracks[i].id < 1 || c->tracks[i].id > 0x3FFFFFFF) return 0;
        if (c->tracks[i].start_x < 0 || c->tracks[i].start_x >= 160) return 0;
        if (c->tracks[i].last_x  < 0 || c->tracks[i].last_x  >= 160) return 0;
        if (c->tracks[i].last_y  < 0 || c->tracks[i].last_y  >= 120) return 0;
        if (c->tracks[i].age < 1 || c->tracks[i].age > ARGUS_MAX_AGE) return 0;
        if (c->tracks[i].missed < 0 || c->tracks[i].missed > ARGUS_MAX_MISSED) return 0;
    }
    if (ativos != c->n_tracks) return 0;
    return 1;
}
```

Esta versão de `inv_extra` exclui o estado de partida inalcancável a partir de `argus_init` porque:

1. O estado de partida tem `n_tracks = 1` e `tracks[0].active = 1`, o que é impossível em uma execução real após `argus_init` porque `n_tracks` só aumenta e `tracks[i].active` só muda para 1 quando uma detecção é processada, o que requer pelo menos uma detecção.

2. O estado de partida tem `ev_count = 1` e `ev_dropped = 0`, o que é impossível em uma execução real porque `ev_count` só aumenta e `ev_dropped` só aumenta quando um evento é descartado, o que requer pelo menos um evento descartado.

3. O estado de partida tem `next_id = 129`, o que é impossível em uma execução real porque `next_id` só aumenta e nunca volta a 1.

Portanto, o estado de partida é inalcancável e esta versão de `inv_extra` garante que o estado seja válido em todas as execuções reais.
