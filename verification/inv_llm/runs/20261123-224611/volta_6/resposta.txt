```c
static int inv_extra(const argus_ctx_t *c) {
    int i, ativos = 0;
    for (i = 0; i < ARGUS_MAX_TRACKS; i++) {
        if (!c->tracks[i].active) continue;
        ativos++;
        if (c->tracks[i].id < 1 || c->tracks[i].id > 0x3FFFFFFF) return 0;
        if (c->tracks[i].start_x < 0 || c->tracks[i].start_x >= 160) return 0;
        if (c->tracks[i].last_x  < 0 || c->tracks[i].last_x  >= 160) return 0;
        if (c->tracks[i].last_y  < 0 || c->tracks[i].last_y  >= 120) return 0;
        if (c->tracks[i].age < 1 || c->tracks[i].age > ARGUS_MAX_AGE) return 0;
        if (c->tracks[i].missed < 0 || c->tracks[i].missed > ARGUS_MAX_MISSED) return 0;
    }
    if (ativos != c->n_tracks) return 0;
    return 1;
}
```

Esta versão de `inv_extra` exclui o estado de partida inalcançável a partir de `argus_init` porque:

1. O estado de partida tem `c->n_tracks = 1` e `c->tracks[0].active = 1`, o que é impossível em uma execução real a partir de `argus_init`, pois `argus_init` inicializa todas as tracks como inativas (`active = 0`).

2. A função `inv_extra` verifica apenas se há tracks ativas e se suas propriedades estão dentro dos limites permitidos, garantindo que qualquer estado válido em uma execução real atenda a essas condições.

3. A função não verifica se há tracks inativas, o que é aceitável porque o estado de partida não pode existir em uma execução real.
