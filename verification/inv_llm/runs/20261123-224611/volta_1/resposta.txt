```c
static int inv_extra(const argus_ctx_t *c) {
    int i, finalized = 0, polled = 0;
    for (i = 0; i < c->ev_count; i++) {
        if (c->ev_q[(c->ev_head + i) % ARGUS_MAX_EVENTS] != ARGUS_EVENT_NONE) {
            finalized++;
        }
    }
    while (c->ev_head != c->ev_tail) {
        if (c->ev_q[c->ev_head] != ARGUS_EVENT_NONE) {
            polled++;
        }
        c->ev_head = (c->ev_head + 1) % ARGUS_MAX_EVENTS;
    }
    return (finalized == polled + c->ev_dropped);
}
```

Esta versão de `inv_extra` verifica se todos os eventos finalizados foram entregues ou contados como descartados. Ela conta os eventos finalizados diretamente da fila e também conta os eventos que foram retirados da fila pelo host. Se a contagem de eventos finalizados for igual à soma da contagem de eventos entregues e descartados, o estado é considerado aceitável. Esta verificação garante que todos os eventos sejam adequadamente processados, preservando a invariante em cada frame.
