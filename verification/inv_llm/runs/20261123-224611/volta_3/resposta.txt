```c
static int inv_extra(const argus_ctx_t *c) {
    int i, ativos = 0;
    for (i = 0; i < ARGUS_MAX_TRACKS; i++) {
        if (!c->tracks[i].active) continue;
        ativos++;
        if (c->tracks[i].id < 1 || c->tracks[i].id > 0x3FFFFFFF) return 0;
        if (c->tracks[i].start_x < 0 || c->tracks[i].start_x >= 160) return 0;
        if (c->tracks[i].last_x  < 0 || c->tracks[i].last_x  >= 160) return 0;
        if (c->tracks[i].last_y  < 0 || c->tracks[i].last_y  >= 120) return 0;
        if (c->tracks[i].age < 1 || c->tracks[i].age > ARGUS_MAX_AGE) return 0;
        if (c->tracks[i].missed < 0 || c->tracks[i].missed > ARGUS_MAX_MISSED) return 0;
    }
    if (ativos != c->n_tracks) return 0;
    return 1;
}
```

Esta versão de `inv_extra` exclui o estado de partida inviável onde `id` é negativo ou muito grande. Ela garante que todos os `id`s estejam dentro do intervalo válido `[1, 0x3FFFFFFF]`. Isso se preserva em um frame porque:

1. O `id` é inicializado em `1` em `argus_init` e nunca é alterado para valores inválidos.
2. O `id` é incrementado sempre que um novo track é criado, garantindo que sempre seja positivo e dentro do intervalo.
3. O `id` é decrementado apenas quando um track é finalizado, e isso só acontece quando o track é removido da lista, mantendo a invariante.
